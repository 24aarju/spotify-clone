🎵 Spotify Clone

A responsive Spotify-inspired music player built using **HTML, CSS, and JavaScript**.  
This project allows users to browse music albums, play songs, pause/resume tracks, use previous/next controls, and control playback using a seekbar.

 Live Demo

 [Spotify Clone - Live Demo](https://spotify-clone-aarju.vercel.app/)

 Features

-  Play and pause songs
-  Previous and ⏭️ Next song controls
-  Dynamic album/playlist loading
-  Multiple songs and playlists
-  Song duration and current-time display
-  Interactive seekbar
-  Responsive design for different screen sizes
-  Mobile sidebar/hamburger menu
-  Play songs directly from playlists
-  Dynamic song loading
-  Deployed on Vercel

 Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive design
- **JavaScript** – Music player functionality and dynamic content
- **Font Awesome** – Icons
- **Git & GitHub** – Version control
- **Vercel** – Deployment
